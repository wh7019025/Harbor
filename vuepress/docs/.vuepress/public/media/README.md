# Harbor homepage media

`harbor-workflow.mp4` is a 22.24-second edited capture made on 2026-10-14.
It shows the repository's original App.vue / TaskClickView.vue and PanelView.vue,
served through a temporary localhost Vite transport adapter to a real harbor_core.
This is not a native desktop screen recording. Task states and log output came
from actual processes; desktop window buttons were transport stubs in capture.

Sequence: start the Hello Harbor demo group, select its live Hello World Loop
log, open the repository's examples/webpage_view Robot Panel. The Robot Panel
backend used mock data, without a robot connection. Screenshots were assembled
at 25 fps with H.264 encoding; gaps between capture segments were cut. The first
segment retains the previous demo run's log until the new live log is selected.

The temporary demo workspace was stopped after capture and the previous Core
workspace restored. No personal Core log is included. Poster is a frame of the
same capture; captions are in harbor-workflow.vtt. Refresh footage when the actual
application UI changes. The homepage does not connect to a live Core.

On 2026-10-15, instructional cursor, click ripples, and Chinese action labels
were burned into the footage at the three operation points. These are editorial
annotations, not a captured native pointer; this is labeled in the video.

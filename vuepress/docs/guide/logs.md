# 日志

Core 同时提供实时输出和历史日志。Workspace 的日志位于：

```text
~/.harbor/workspace/<workspace-id>/log
```

## 实时日志

任务运行时，GUI 持续读取当前输出。切换页面不会改变任务进程，重新进入任务时可继续查看。

## 历史日志

Harbor 为每个任务保留最近的日志记录，并在界面中提供最近 50 条。日志文件名包含任务信息与启动时间。

## 复制日志

为避免把超大日志送入剪贴板，复制操作默认取末尾 128 行，可选择 256、512 或 1024 行；上限为 1024 行。

## 排查建议

- 启动失败时先查看任务日志顶部的命令和工作目录。
- 远端失败时同时检查 Core 日志与任务日志。
- 图形程序报 `could not connect to display` 时，检查远端桌面会话是否存在，参见[远端运行](./remote.md)。
